# SevaLink - Community Events Platform

Live Site: https://YOUR-LIVE-URL.vercel.app

SevaLink holo ekta community-driven platform jekhane user-ra shomaj seba mulok event create, join ar track korte pare.

## Features

- Email/password ar Google diye authentication (BetterAuth)
- Event create, update ar delete (shudhu owner pare)
- Upcoming events er search ar type filter
- Ek click e event join ar Joined Events page
- JWT diye protected API
- Light/Dark theme toggle
- Fully responsive design
- Loading skeleton ar profile update

## Tech Stack

Next.js (App Router), DaisyUI, BetterAuth, Express.js, MongoDB
